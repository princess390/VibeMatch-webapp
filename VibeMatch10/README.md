VibeMatch

Hangulatalapú tartalomajánló webalkalmazás filmekhez, sorozatokhoz, könyvekhez és zenékhez.

Használat

A projekt statikus weboldalként futtatható.

1. Nyisd meg az `index.html` fájlt böngészőben.
2. Vagy töltsd fel GitHubra, majd kapcsold be a GitHub Pages funkciót.

## Fő funkciók

- hangulat szerinti keresés;
- filmek, sorozatok, könyvek és zenék ajánlása külső API-k alapján;
- kártyás találati lista borítóképekkel;
- részletes tartalomnézet modalban;
- bejelentkezés és mentés Supabase használatával;
- reszponzív, mobilbarát felület.

## Megjegyzés

A mentési funkció Supabase beállítást igényel. A keresési és ajánlási funkciók külön adatbázis feltöltése nélkül, külső API-k segítségével működnek.
